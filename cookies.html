Cookies & local storage

Prepared: 15 October 2026

Website storage

This website’s code sets no cookies and does not use localStorage, sessionStorage, advertising IDs or a service worker. Language selection uses ordinary English and German page links. No language profile is stored.

Browser and host behavior

Your browser may cache images and other site files as part of normal browsing. GitHub Pages processes connection data to deliver and protect the website. No cookie banner is included because this implementation adds no optional tracking or storage requiring a preference. This does not mean that visiting a hosted website transmits no data. Read the privacy policy for hosting and support processing.

Game saves are separate

The Android game’s local saves are separate from this website. Clearing browser data does not delete the game’s save. Use Android’s app storage controls for local game data; deletion removes progress.
